# Wand Toolkit（万能权杖）

自用的 Minecraft 基岩版（Bedrock）行为包，纯脚本实现，不需要资源包。

**一根权杖，一个菜单，管理世界需要的功能全在里面**：满附魔、整理背包、常驻 Buff、召唤 Boss、昼夜切换、回家传送。

| | |
|---|---|
| 安装文件 | `WandToolkit.mcpack` |
| 最低游戏版本 | 1.21.30 |
| 获取权杖 | `/scriptevent wand:give` |

## 📦 安装

1. 双击 `WandToolkit.mcpack`，游戏会自动导入（或在游戏里 设置 → 存储 → 导入）。
2. 进入世界设置 → **行为包**，启用这个包。
3. 世界需要**开启作弊**（权杖需要用 `/scriptevent` 指令获取）。

进入世界后，聊天栏会显示加载成功的横幅，看到横幅就说明包生效了。

## 🪄 获取和使用

在聊天栏输入：

```
/scriptevent wand:give
```

会得到一根蓝色名字的「万能权杖」（本体是烈焰棒）。**手持权杖**，手机长按 / PC 右键 / 手柄按使用键，菜单就会弹出。

> 注意：权杖是靠「改名烈焰棒」识别的，不要用铁砧改它的名字，改了就不认了。再要一根重新输指令即可。

## ⚔️ 一键满附魔

| 选项 | 功能 |
|---|---|
| 全部满附魔 | 装备栏 + 背包里所有能附魔的物品一次附满 |
| 选择单件附魔 | 从列表里挑一件 |

- 自动跳过并**移除诅咒附魔**。
- **互斥附魔按固定优先级取舍**，物品上已有的低优先附魔会被替换：

  | 冲突组 | 优先级 |
  |---|---|
  | 近战伤害 | 锋利 > 致密（重锤）> 破甲 > 亡灵杀手 > 节肢杀手 |
  | 盔甲保护 | 保护 > 火焰保护 > 爆炸保护 > 弹射物保护 |
  | 挖掘 | 时运 > 精准采集 |
  | 靴子 | 深海探索者 > 冰霜行者 |
  | 弓 | 无限 > 经验修补 |
  | 弩 | 多重射击 > 穿透 |
  | 三叉戟 | 忠诚 + 引雷 > 激流 |

- 附魔扫描的是整个背包 + 装备栏，物品**不需要拿在手上**。

## 🎒 整理背包

| 选项 | 功能 |
|---|---|
| 一键整理 | 同类物品合并；工具武器排到快捷栏，方块、矿物、杂物依次靠后，食物固定在背包末尾；垃圾（腐肉、毒马铃薯）自动删除 |
| 矿物合成块 | 铁锭×9 → 铁块 等 12 种配方（铁/金/铜/钻石/绿宝石/红石/煤/青金石/下界合金/三种粗矿），零头保留 |
| 矿物块拆解 | 上面的反向操作 |
| 存入附近箱子 | 把背包物品自动存进周围 6 格内的箱子/木桶，规则见下 |
| §c清空背包 | 清空背包（弹二次确认；权杖和穿着的盔甲会保留） |

背包放不下的部分会掉在脚下并提示，不会凭空消失。

### 箱子分类存储

在箱子**任意一面（含顶部）**紧贴放一块告示牌，写：

```
[storage]
ores
```

第一行固定 `[storage]`，第二行是分类标签，中英文都认：

| 标签 | 收纳内容 |
|---|---|
| `ores` / `矿物` | 矿石、锭、粗矿、宝石、矿物块 |
| `food` / `食物` | 所有食物 |
| `tools` / `工具` / `武器` | 工具和武器 |
| `blocks` / `方块` | 建筑方块 |
| `misc` / `杂物` | 不属于以上分类的东西 |
| `all` / `全部` | 什么都收 |

规则：

- **有标签的箱子**优先收货，装满自动溢出到下一个同类箱子。
- **没有标签的箱子**按「快速堆叠」逻辑：只收它**已经装有**的物品种类，不会乱塞。
- 大箱子按一个容器计算，不会重复统计。
- 权杖本体永远不会被存进箱子。

## ✨ 常驻 Buff

| 选项 | 功能 |
|---|---|
| 配置常驻 Buff » | 勾选式表单，勾上开启、取消勾选关闭，提交后立即生效 |
| 清除所有效果 | 清掉身上全部状态效果（包括中毒、凋零等负面效果），并同时关闭常驻配置 |

- 勾选的 buff 由脚本**每 5 秒检查一次、快到期就自动续杯**，永不过期，药水粒子已隐藏。
- 配置存在玩家身上，**掉线重连、退出重进存档、死亡重生都会自动恢复**；多人各自独立。
- 夜视不会闪屏（时长始终保持在 30 秒以上）。

**可选 Buff（默认等级）**：速度 II、急迫 II、力量 II、抗性提升 II、生命恢复 II、跳跃提升 II、防火、水下呼吸、夜视、缓降、饱和、生命提升 II（+4❤）。

### 🎉 整活模式

勾选表单顶部的「整活模式」开关后，buff 按 **255 级**（游戏允许的最大等级）施加：力量一拳秒杀、急迫瞬间破坏、速度快到飞起……

- **跳跃提升是例外**：整活模式下按 VI 级施加，大约跳 6 格——255 级会跳上天要等半天才落地，实测不好玩。
- 防火、夜视等开关型效果没有等级，整活模式下不变。
- 玩腻了取消勾选即可恢复正常等级；「清除所有效果」也能一键清掉 255 级 buff。
- ⚠️ 跳 6 格落地也会掉一点血，怕摔可以搭配「缓降」或「生命恢复」。

## 👹 召唤 Boss

| 菜单项 | 说明 |
|---|---|
| 凋灵 | ⚠️ 生成时会爆炸，弹二次确认 |
| 末影龙 | ⚠️ 会在附近飞行并破坏沿途方块，弹二次确认 |
| 监守者 | ⚠️ 伤害极高，弹二次确认 |
| 远古守卫者 | 激光攻击，会施加挖掘疲劳 |
| 劫掠兽 | 冲撞攻击 |
| 唤魔者 | 召唤尖牙和恼鬼，掉落不死图腾 |
| 清除已召唤的 Boss | 移除**当前维度**里本权杖召唤的全部 Boss |

- Boss 出现在你**面前 6 格**处（末影龙在上方 8 格起飞）；想在哪召唤，面朝哪里再点即可。
- 权杖召唤的 Boss 都带隐藏标记，「清除已召唤的 Boss」**只清这些**，不会误伤自然生成的怪；清除是直接消失，没有死亡动画也不掉落物品。
- 一次点击召唤一只，想要多只就多点几次。
- ⚠️ 在生存模式下召唤凋灵/监守者前请先做好逃生准备；末影龙在主世界会破坏地形，建议在空旷处玩。

## 🔧 从源码打包

源码在 `src/`，需要 Node.js（无第三方依赖）：

```bash
npm run build     # 打包成 WandToolkit.mcpack
npm run check     # 校验仓库里的 .mcpack 和 src/ 是否一致
```

打包结果是确定性的（条目排序固定、时间戳固定），所以源码没变时重新打包不会产生无谓的 git diff。

`npm run check` 比对的是**内容**（条目名、大小、CRC），不是原始字节——zlib 的压缩输出在不同 Node 版本之间可能不一样，比字节会导致本地和 CI 结论不一致。

### 发布

`.github/workflows/release.yml` 在 `src/` 有改动推到 `main` 时运行：

1. `npm run check` —— 仓库里的 `.mcpack` 和 `src/` 不一致就直接失败（代替了以前「记得重新 Compress-Archive」那一步）；
2. 读 `src/manifest.json` 的版本号，**已经有同名 tag 就跳过**，没有才发布；
3. 打 `v<版本号>` tag，创建 Release，附上 `WandToolkit.mcpack`，发布说明由 `src/`、`tools/` 下的 commit 自动生成。

所以**发版方式就是改 `src/manifest.json` 里的版本号**，重新打包后一起提交。CI 不会向仓库写任何东西。

### 目录结构

```
src/
  manifest.json        版本号的唯一来源（构建时注入脚本）
  scripts/
    main.js            入口：主菜单 + 事件注册
    core.js            权杖本体、表单封装、事件接线
    enchant.js         满附魔
    inventory.js       整理 / 矿物转换 / 存箱子 / 清空
    buffs.js           常驻 Buff + 整活模式
    bosses.js          召唤与清除 Boss
    world.js           昼夜切换、家
tools/build.mjs        打包脚本（含一个极简的确定性 ZIP 写入器）
```

### 改点什么

- **垃圾清单**：`src/scripts/inventory.js` 里的 `JUNK_IDS`
- **矿物合成配方**：同文件的 `COMPRESS_MAP`
- **附魔优先级**：`src/scripts/enchant.js` 里的 `EXCLUSIVE_GROUPS`
- **可选 Buff**：`src/scripts/buffs.js` 里的 `BUFFS`
- **Boss 列表**：`src/scripts/bosses.js` 里的 `BOSSES`
- **版本号**：只改 `src/manifest.json`，脚本里的 `VERSION` 由构建注入
